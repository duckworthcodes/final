# MahaPoojan

Static devotional platform prototype — puja booking, temples, live darshan, panchang, horoscope, and sacred library.

## Quick start

Open `index.html` in a browser, or serve locally:

```bash
python -m http.server 8080
# visit http://localhost:8080
```

## Project structure

```
├── index.html              Homepage
├── puja.html               Puja catalog + booking modal
├── puja-booking.html       Dedicated booking form
├── temples.html            Temple directory
├── darshan.html            Live darshan (UI demo)
├── chadhava.html           Chadhava offerings
├── panchang.html           Daily panchang
├── horoscope.html          Horoscope
├── library.html            Sacred library
├── bhajans.html            Bhajans, festivals & store
├── about.html              About us
├── legal.html              Contact & legal
└── assets/
    ├── css/shared.css      Shared nav + mobile menu
    ├── js/shared.js        Mobile nav + animations
    ├── js/temples-data.js  Temple catalog data
    └── images/             Optimized image assets
```
